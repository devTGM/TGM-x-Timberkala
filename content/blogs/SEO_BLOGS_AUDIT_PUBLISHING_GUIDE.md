## 4. How to Publish in Shopify Admin (Takes 2 Minutes per Article)

1. Navigate to **Shopify Admin > Online Store > Blog Posts** (`/admin/articles`).
2. Click **Add blog post**.
3. Set the **Title** to the Article Title above.
4. Click the **`<>` (Show HTML)** button in the Rich Text Content Editor.
5. Copy the contents of the respective `.html` file from `content/blogs/` and paste it directly into the HTML field.
6. Set the **Excerpt** to the 45-50 word Direct Answer text.
7. Click **Edit website SEO** at the bottom:
   - Set **Page title** to the meta title above.
   - Set **Meta description** to the meta description above.
   - Set **URL and handle** to the target slug above.
8. Set **Author** to `Master Woodcraft Atelier` and **Blog** to `Blogs` (or `Journal`).
9. Click **Save** and **Publish**.
